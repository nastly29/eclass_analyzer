# ECLASS Diff & Mapping Tool 

Вебзастосунок для автоматизованого порівняння версій ECLASS, аналізу структурних змін у класах та знаходження потенційних замінників для вилучених класів за допомогою NLP-моделі.

---

### Основні можливості

* **Загальна статистика:** Порівняльний аналіз кількості класів між версіями, фіксація доданих та вилучених об'єктів.
* **Векторний мапінг:** Автоматичний пошук замінників для вилучених класів.
* **Деталізація за сегментами:** Аналіз структурних змін і формування татистики за сегментами.
* **Внутрішні зміни:** Відстеження редагувань `Definition` та додавання/вилучення властивостей (`Property`).
* **Експорт звітів:** Завантаження всіх сформованих таблиць у форматі CSV.

---

### Передумови
Переконайтеся, що на ПК встановлено **Python 3.10** або новішу версію.

--- 

### Встановлення залежностей
Відкрийте термінал у папці проєкту та виконайте: `pip install -r requirements.txt`.

---

### Запуск застосунку
У терміналі виконайте команду: `streamlit run app.py`.
Застосунок автоматично відкриється у браузері за адресою *http://localhost:8501*.

---

### Структура необхідних вхідних CSV-файлів
Для повноцінного аналізу на бічній панелі потрібно завантажити 6 CSV-файлів (по 3 для старої та оновленої версій ECLASS):
* **Класи**(`CC_en.csv`): Базовий перелік категорій.
* **Зв'язки**(`CC_PR_en.csv`): Структура прив'язки характеристик до категорій.
* **Властивості**(`PR_en.csv`): Словник усіх характеристик.

---

### Налаштування аналізу в інтерфейсі
* **Сегменти для мапінгу**: Фільтрація за двозначним кодом сегмента. За замовчуванням обробляються всі сегменти.
* **Кількість замінників (Top-K)**: Кількість потенційних кандидатів з нової версії для кожного вилученого класу.
* **Поріг схожості (%)**: Мінімальний відсоток схожості замінника #1. Значення нижче порогу позначаються як такі, що потребують ручної перевірки.
